# PWA - Sistema de Asistencia CBTa 47

Sistema de gestión de pases de lista para docentes.

## 🚀 Avances al 6 de Mayo de 2026
- **Módulo de Asistencia:** Soporte para estados: Asistencia (A), Falta (F), Retardo (R) y Justificante (J).
- **Persistencia en Firebase:** Integración con Firestore Database y configuración de reglas de seguridad por tiempo.
- **Multi-sesión:** Capacidad para guardar múltiples pases de lista en un mismo día mediante marcas de tiempo (HH-mm-ss).
- **Historial:** Vista de consulta para pases de lista previos por grupo y fecha.

## 🛠️ Tecnologías
- JavaScript (ES6+)
- Firebase Firestore
- Bootstrap 5
- Service Workers (PWA)
